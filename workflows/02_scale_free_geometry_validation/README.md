# Scale-free breakpoint-geometry validation

This is the strongest freshly reproduced breakpoint-only internal definition.
It is an outcome-linked nested-validation recipe, not a frozen patient-level
score and not the report-readable nine-window shortlist.

## Inputs

- event-called SEG data with sample ID, chromosome, start, end, and event;
- explicit genome build;
- sample ID, recurrence time, and recurrence event;
- patient ID when multiple tumors can come from one patient; and
- optional recorded WHO and prespecified integrated-grade comparators.

## Fixed feature definition

The model uses the 56 `shape` features generated by
`archive/method-development/analysis/03_geometry_route_bakeoff.R`. These are
normalized summaries of breakpoint position, dispersion, concentration,
entropy, and loss/gain route asymmetry. The `shape` set excludes the 18
topology features, eight complexity/fragmentation variables, clinical
covariates, and thresholded arm-level SCNA calls.

The exact inclusion rule and validation parameters are machine-readable in
[`model_spec.yml`](model_spec.yml). Do not substitute the larger topology,
geometry-plus-complexity, or coarse-route-map sets while retaining these AUCs.

## Validation

Run the lineage scripts in order after setting `MENIBREAK_PROJECT_ROOT` to the
analysis project containing the analysis-ready institutional data:

```sh
R_PROFILE_USER=/dev/null Rscript \
  archive/method-development/analysis/03_geometry_route_bakeoff.R

R_PROFILE_USER=/dev/null Rscript \
  archive/method-development/analysis/04_scale_free_geometry_multihorizon.R
```

The second script uses ten repetitions of patient-grouped five-fold outer
validation. Within every outer training set, `cv.glmnet` selects the penalty
using patient-grouped inner folds; held-out patients do not influence fitting.

## Fresh internal benchmark

| Cohort | 3 years | 5 years | 7 years |
|---|---:|---:|---:|
| Broad | 0.764 | 0.769 | 0.755 |
| Restricted transport | 0.715 | 0.747 | 0.722 |

The restricted estimates apply the broad-cohort held-out scores without
restricted refitting. With only 22, 37, and 43 events, they are less stable than
the broad estimates. See
[`../../inst/extdata/internal_breakpoint_only_benchmark_20260822.csv`](../../inst/extdata/internal_breakpoint_only_benchmark_20260822.csv).
