# Security and sensitive-data reporting

MeniBreak is designed for local research use and does not transmit input data.
Do not include protected health information, identifiable sample metadata, or
restricted cohort data in a public issue.

For a suspected code vulnerability, open a private GitHub security advisory if
that feature is enabled. For an accidental data disclosure, remove public
access immediately and follow the affected institution's incident-response and
IRB/DUA procedures; deleting a file in a later commit does not remove it from
Git history.
