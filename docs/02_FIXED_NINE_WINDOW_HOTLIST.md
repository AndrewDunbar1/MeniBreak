# 2. Dynamic top-eight procedure and stability shortlist

## Literal reconstruction of the historical narrative

The historical “eight-window panel” was not one frozen list of eight regions.
The report describes it as an outcome-linked selection procedure:

1. Divide each chromosome arm into 20 equal arm-relative bins, oriented from
   telomere (0) to centromere (1).
2. Encode a bin as 1 when any eligible copy-number segment boundary falls in it.
3. Remove candidates supported by fewer than 20 tumors.
4. Within every outer training fold, rank candidates by a chi-square association
   test with that horizon's binary recurrence endpoint.
5. Retain the top eight, standardize them using training-fold statistics, and
   fit binomial elastic-net logistic regression. The later executable
   reconstruction uses `l1_ratio=0.25` and `C=0.1`; the source itself does not
   specify `C`.
6. Score only the held-out patients.
7. Repeat patient-grouped 5-fold validation five times.

Use `mbpr top8-candidates` followed by
[`workflows/01_dynamic_top8_validation/run_validation.py`](../workflows/01_dynamic_top8_validation/run_validation.py).
Selection, scaling, and fitting must never see the outer test fold.

The dynamic procedure requires outcomes and model fitting. It cannot provide a
locked score for an outcome-free sample, and the eight selected windows may
differ across folds, horizons, and cohorts.

## What the nine displayed windows mean

The historical report displays nine unique 5%-of-arm windows as selected in at
least 40% of folds at one or more horizons. They are a descriptive **stability
union**, not a nine-feature model and not a universal top-eight list. Their
reported frequencies cannot be regenerated by the report's stated selector.

The authoritative descriptive table is
[`inst/extdata/hotlist_v1.csv`](../inst/extdata/hotlist_v1.csv). Its extraction
is exact: both segment boundaries are counted after arm assignment, using
left-closed/right-open intervals and build-specific arm coordinates. GRCh38 is
handled with arm-relative coordinates and no silent breakpoint liftover.

```sh
./mbpr hotlist-extract --segments cohort.seg --format auto \
  --genome-build GRCh37 --output-dir shortlist_results
```

For Heidelberg, the clean first analysis is whether these individual windows
show the same direction, prevalence, and outcome association. A composite fixed
score would be a new model and must not inherit the dynamic procedure's AUCs.

## Historical benchmark status

The recovered August 4 source report attributes broad-cohort top-eight AUCs of
0.702, 0.735, and 0.752 at 3, 5, and 7 years. Those values document what the
report said, but the retained methods and stability table are mutually
inconsistent and fresh implementations do not recreate them. The
machine-readable provenance table is
[`inst/extdata/historical_dynamic_top8_benchmark.csv`](../inst/extdata/historical_dynamic_top8_benchmark.csv)
and is explicitly marked historical/unverified rather than reproduced.
